# SPRING PLUS PROJECT

# Introduction
This project is the backend code for a software that allows users to signup/login, then create their Todos.
The original code was forked from @Nhahan, and later enhanced via applying Spring Security, enhanced AOP and query searches (QueryDSL, JPQL).

# Applied tools
- Spring Security
- JWT
- AOP (Aspect-oriented programming)
- 3-layer architecture
- QueryDSL
- JPQL
